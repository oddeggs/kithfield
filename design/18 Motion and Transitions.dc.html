Motion & transitions
The rule: the thing you touched is the thing that travels. Each storyboard has a live sample you can play, reverse and interrupt, plus 3–6 keyframes, timing and curve from 01 Foundations, what happens when it's interrupted, and its Reduce Motion version. Dashed honey lines show the path of the travelling art.

Notes for the developer
Overlay layer
All travelling art (critters, seeds, fireflies, stickers, parcels, drops) is drawn in one shared transparent overlay above the navigation stack, so elements can leave one screen and land in another. Source and destination register matched IDs; the overlay snapshots the source sprite, hides the original, flies the copy, then reveals the destination.
UI thread
Run transitions on the render thread (SwiftUI matchedGeometryEffect / custom Transaction on iOS, Compose SharedTransitionLayout on Android, Web Animations API on web). Never block on network: travel starts immediately and the destination fills in.
Interruptible springs
Every travel is a spring (motion.sheet: response 0.32, damping 0.9) driven by a target, not a timeline. Retargeting mid-flight keeps position and velocity. Reversal is the same spring to the source.
120 fps
Positions, scales and rotations interpolate at the display rate (120Hz on ProMotion). Only the drawing inside the sprite changes on twos (12fps), so lines wobble by swapping between 2–3 slightly different hand-drawn frames while flying. Hold that rule: smooth paths, hand-drawn faces.
Wobble
In flight, sprites rotate ±3–8° following the path's curvature and swap drawings every 83ms. Landing adds a 2-drawing settle (squash 4%, then rest).
Signature vs standard
Signature: 18-01–18-04, 18-06–18-10, 18-12, 18-13, 18-16, 18-17 are built specially. Standard: 18-05, 18-11 (viewer), 18-14, 18-15 use native zoom, push and sheet transitions with matched elements.
Reduce Motion
Every transition collapses to a 200ms cross-fade (motion.fade). Travelling art never moves; destination state appears directly.
